# Как скачать тестовый APK
1. Откройте вкладку Actions в репозитории.
2. Выберите Android APK.
3. После успешной сборки откройте последний запуск.
4. В разделе Artifacts скачайте SousVide-debug-apk и извлеките APK.
5. Это тестовая версия: подпись debug APK между CI-запусками может меняться. Для обычных обновлений позже нужна постоянная release-подпись.
